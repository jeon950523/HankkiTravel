# 스크린샷

이 디렉터리에는 포트폴리오에서 서비스 사용 흐름을 설명하는 캡처를 둡니다.

| 파일 | 설명 |
| --- | --- |
| `map-planner-desktop.png` | 제주 여행의 지도와 방문 순서를 함께 보여주는 일자별 일정 플래너 |
| `restaurant-recommendation-desktop.png` | 가족 조건과 이동 부담을 반영해 식당을 추천·선택하는 흐름 |
| `final-plan-desktop.png` | 선택한 관광지·식당과 이동 부담을 정리한 완성 여행 플랜 |

향후에는 다음 장면처럼 실제 서비스 사용 흐름을 설명하는 캡처만 추가합니다.

- 가족 여행 조건 입력
- 추천 근거가 포함된 음식점 후보
- Kakao Map 기반 일자별 일정
- 이동 부담 경고와 플랜 조정
- 여행 완료 화면

캡처 전에는 이름, 주소, 인증 상태, 브라우저 확장 프로그램, 운영 대시보드, API 키가 보이지 않는지 확인합니다. 실제 사용자 데이터와 관리자 화면은 공개하지 않습니다.
